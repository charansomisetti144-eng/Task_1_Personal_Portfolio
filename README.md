# TASK 1 - STATIC PORTFOLIO WEBSITE

## Project Title

Responsive Personal Portfolio Website

## Project Description

This project is a modern and responsive personal portfolio website developed using HTML5, CSS3, JavaScript, and Bootstrap 5.

The website is designed to present personal information, technical skills, completed projects, and contact details in a clean and professional format. The interface follows a modern dark theme and is optimized for desktop, tablet, and mobile devices.

JavaScript is used to validate the contact form and provide appropriate error and success messages based on user input.

---

## Objective

The objective of this project is to create a visually appealing and responsive static portfolio website that demonstrates fundamental frontend web development skills.

The project focuses on:

* Creating a structured webpage using HTML5
* Designing a professional interface using CSS3
* Using Bootstrap for responsive layouts
* Implementing interactive functionality with JavaScript
* Creating a Projects section to showcase development work
* Implementing contact form validation
* Ensuring compatibility across different screen sizes

## Contact Form Validation

The contact form uses JavaScript to perform client-side validation.

The validation includes:

* Checking whether required fields are empty
* Validating the email address format
* Checking the minimum message length
* Displaying appropriate validation error messages
* Displaying a success message when all entered information is valid
* Resetting the form after successful validation

Note: The current implementation performs client-side validation only. It does not send or store the submitted information on a server.
