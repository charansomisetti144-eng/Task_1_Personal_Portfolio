# 📌 Project Overview

The **Responsive Personal Portfolio Website** was created to demonstrate fundamental front-end web development skills by building a fully responsive personal portfolio.

The website includes multiple sections such as:

- Home
- About
- Skills
- Projects
- Contact
- Footer

The application is designed to work smoothly across desktops, tablets, and mobile devices.

---

# 🎯 Project Objectives

- Build a responsive portfolio website.
- Apply semantic HTML5.
- Design modern layouts using CSS3.
- Use Bootstrap 5 for responsiveness.
- Add JavaScript interactivity.
- Improve user experience.
- Practice Git and GitHub workflow.
- Deploy the project online.

        │
        ▼

Cloudflare Pages provides:

- Automatic HTTPS
