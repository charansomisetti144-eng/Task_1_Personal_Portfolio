# 🚀 Deployment

## Introduction

Deployment is the final stage of the software development lifecycle, where the completed application is made accessible to users over the internet.

After the development, testing, and debugging phases were completed, the **Responsive Personal Portfolio Website** was deployed using **Cloudflare Pages**, a modern static website hosting platform. Cloudflare Pages provides fast global content delivery, secure HTTPS, automatic deployments, and seamless integration with Git repositories.

Using Cloudflare Pages ensured that the website became publicly accessible while maintaining excellent performance and reliability.

---

# 🎯 Objectives of Deployment

The deployment process was carried out to achieve the following objectives:

- Publish the website online.
- Make the project accessible from anywhere.
- Verify the production version.
- Test the live application.
- Demonstrate project completion.
- Share the portfolio with recruiters and evaluators.
- Gain practical deployment experience.

# 🌐 Deployment Platform

## Cloudflare Pages

The project was deployed using **Cloudflare Pages**, a platform designed for hosting static websites.

### Why Cloudflare Pages?

- Free static website hosting
- Fast global Content Delivery Network (CDN)
- Automatic HTTPS
- GitHub integration
- Automatic deployments
- Reliable performance
- Easy project management

Cloudflare Pages was selected because it provides a simple and efficient deployment workflow for front-end projects.

The deployment process followed the workflow below.

```text
Develop Website
        │
        ▼

        ▼

        │
        ▼

        │
        ▼

        │
        ▼
Connect Repository to Cloudflare Pages
        │
        ▼
Build Project
        │
        ▼

        │
        ▼
```

This workflow ensured that the deployed version matched the latest source code.
