# 🌐 HTML5

## Overview

HTML5 (HyperText Markup Language Version 5) is the standard markup language used to create the structure and content of web pages.

It defines how information is organized and displayed within a browser.

HTML5 was used to:

- Build the webpage structure
- Create navigation menus
- Design content sections
- Add forms
- Display text and images
- Organize webpage content
