# 📱 Responsive Design

## Introduction

Responsive Web Design (RWD) is a modern web development approach that enables a website to automatically adjust its layout, content, and visual elements according to the screen size and device being used.

For the **Responsive Personal Portfolio Website**, responsiveness was one of the primary internship requirements. The website was designed to provide a consistent and user-friendly experience across desktops, laptops, tablets, and smartphones without requiring separate versions of the website.

By combining HTML5, CSS3, Bootstrap 5, and Media Queries, the portfolio delivers an adaptive interface that remains functional and visually appealing on different screen resolutions.

# 📐 Responsive Design Workflow

The website adapts its layout through the following process.

```text
User Opens Website
         │
         ▼
Browser Detects Screen Size
         │
         ▼
Bootstrap Grid Loads
         │
         ▼
CSS Media Queries Apply
         │
         ▼
Layout Adjusts Automatically
         │
         ▼
Responsive Website Displayed
```

This automatic adaptation happens entirely within the browser.

# 🅱️ Bootstrap Grid System

Bootstrap's responsive **12-column Grid System** was used to organize webpage content.

```text
Desktop
──────────────────────────────
| 4 | 4 | 4 |

Tablet
──────────────────────────────
|    6    |    6    |

Mobile
──────────────────────────────
|     12      |
|     12      |
|     12      |
```

The grid automatically rearranges components depending on the available screen width.

---

# 📏 Media Queries

CSS Media Queries were used to apply different styles for different screen sizes.

Typical responsive breakpoints include:

| Screen Size | Approximate Width |
|--------------|------------------:|
| Extra Small (Mobile) | Below 576px |
| Small | 576px and above |
| Medium | 768px and above |
| Large | 992px and above |
| Extra Large | 1200px and above |

Media Queries allow the website to modify layouts, font sizes, spacing, and component positioning automatically.
