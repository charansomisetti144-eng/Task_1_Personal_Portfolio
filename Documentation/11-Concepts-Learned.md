# 🧠 Concepts Learned

## Introduction

The development of the **Responsive Personal Portfolio Website** provided an opportunity to apply theoretical knowledge in a practical environment. Throughout this project, several fundamental front-end development concepts were explored and implemented.

Rather than focusing only on writing code, this project emphasized understanding how different web technologies work together to create responsive, interactive, and user-friendly websites.

By completing this internship task, practical experience was gained in HTML5, CSS3, Bootstrap 5, JavaScript, responsive web design, project organization, testing, and deployment.

## CSS Box Model

Every HTML element follows the CSS Box Model.

```text
Margin
   ↓
Border
   ↓
Padding
   ↓
Content
```

Understanding the Box Model helped maintain proper spacing and alignment throughout the website.
