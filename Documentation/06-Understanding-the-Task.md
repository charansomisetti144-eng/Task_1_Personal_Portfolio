# 🧠 Understanding the Task

## Introduction

Before starting the development of any software project, it is important to thoroughly understand the problem statement and the expected outcome. Writing code without understanding the requirements often leads to poor design, unnecessary features, and difficulty in maintaining the project.

For **Internship Task 1**, the objective was not simply to create a webpage but to build a **responsive personal portfolio website** that demonstrates fundamental front-end development skills using HTML5, CSS3, Bootstrap 5, and Vanilla JavaScript.

Understanding the task before implementation helped establish a clear development plan and ensured that every internship requirement was successfully fulfilled.

---

# 🎯 Objective of Understanding the Task

The primary objective of this phase was to answer the following questions before beginning development:

- What is the purpose of this project?
- Who will use this website?
- What features are required?
- Which technologies should be used?
- What does the internship expect?
- How should the project be organized?
- How can the project be made responsive?
- Which concepts need to be learned before coding?

Answering these questions reduced confusion during development and helped create a structured workflow.

---

# 📌 Understanding the Problem Statement

The internship task required the development of a **static personal portfolio website**.

The website should:

- Represent the developer professionally.
- Showcase technical skills.
- Display completed projects.
- Provide contact information.
- Work correctly on different screen sizes.
- Include basic JavaScript interactivity.

Unlike a simple webpage, a portfolio website should create a positive first impression while remaining clean, organized, and easy to navigate.

---

# 💼 Why a Portfolio Website?

A portfolio website serves as a digital resume and personal branding platform.

It allows visitors to quickly understand:

- Who the developer is.
- What technologies they know.
- Which projects they have completed.
- How to contact them.

Instead of sending multiple documents, recruiters and clients can view all important information in one place.

---

Before designing the website, it was important to identify who would visit it.

The primary audience includes:

Understanding the audience helped determine the style, layout, and content of the portfolio.

# 🎯 Expected Outcome

By the end of the project, the portfolio should:

# 📱 Understanding Responsive Design

One of the key internship requirements was responsiveness.

This means the website should automatically adapt to different screen sizes without requiring separate versions.

Responsive design ensures:

- Better user experience.
- Mobile compatibility.
- Improved readability.
- Flexible layouts.
- Professional appearance.

Bootstrap's Grid System, CSS Flexbox, CSS Grid, and Media Queries were selected to achieve responsiveness.
