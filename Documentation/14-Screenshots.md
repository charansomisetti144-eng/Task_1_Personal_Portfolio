# 📌 Screenshot Guidelines

To maintain consistency, the following practices were followed while capturing screenshots:

- Capture images after completing development.
- Use high-resolution screenshots.
- Ensure the browser window is clean and uncluttered.
- Display one complete section per screenshot whenever possible.
- Capture screenshots on desktop, tablet, and mobile layouts.
- Save images using meaningful file names.
- Store all images in the `output/screenshots/` directory.

These practices improve the quality and professionalism of the project documentation.
